# 330 Stables for VORP — first public beta

Free VORP stables for RedM: horses, personal stable, tack, wagons, real 3D previews, riding-horse leading, wagon dismissal, cash/gold purchases, wagon buyback and online player sale requests.

**Please test on a staging copy of your server and send feedback through Issues.**

Download the install ZIP, copy vorp_stables into resources and follow docs/INSTALLATION.md. Existing users must read docs/MIGRATION.md: supported VORP ownership rows are reused, but old custom-inventory contents are not automatically copied.

This is a prerelease. Draft leading defaults off after a live native-task rejection. Native Inventory V2 storage, all map/camera combinations and third-party events are not universally certified. No private server, admin/test helper, secrets or restricted inventory icon pack is bundled.

README lists all eleven locations, configuration examples and features. CHANGELOG and docs/TESTING.md describe scope and validation.
