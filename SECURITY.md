# Security reporting

Do not publish exploits, credentials, private player data or database dumps in public Issues.

Use this repository's **Security → Report a vulnerability** for a private advisory. Include the affected release, conditions and minimal reproduction without real player data. Normal visual/installation bugs belong in Issues.

This beta has best-effort maintenance, no response-time SLA. Only the current beta is being maintained. Wallet and SQL ownership are not one crash-atomic transaction; keep backups and reconcile economy events after process crashes.
