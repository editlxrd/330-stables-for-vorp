# Roadmap

**Still a beta. Built for server owners to test and give feedback.**

These are planned directions, not included-feature promises or dated commitments:

- [ ] Horse status: hunger, thirst, stamina and related needs.
- [ ] Complete native VORP Inventory integration/acceptance across supported versions. Initial adapters exist; old-bag migration and all Inventory V2 variants are not certified.
- [ ] Wagon storage: complete the owner-facing flow and verify it with supported inventory versions. Per-wagon identity/access scaffolding is already present.
- [ ] Horse care/service: brush, feeding, cleaning and useful maintenance actions.
- [ ] Breeding system.
- [ ] Horse age system.
- [ ] Wider native model/map, multiplayer and storage acceptance tests.
- [ ] More quality-of-life features shaped by server-owner feedback.

Riding-horse leading and wagon dismissal are in this beta. Harnessed wagon leading remains experimental/off by default after engine rejection. There is no delivery date or guaranteed custom integration for roadmap items.
